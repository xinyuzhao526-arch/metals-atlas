# 数据口径

本平台不把缺失值解释为零。数据库和 API 使用 `null` 并附带 `missing_reason`；中文“待补”仅是前端展示。

自然年与公司财年分别记录。财年记录必须保存财年标签和财年起始月；季度、YTD 和年度值不自动互相推导。项目 100% 总量、权益、应占和合并口径分别记录，不自动混合。生产环节必须显式保存，不跨矿端含金属、精矿含金属、阴极铜或冶炼产出求和。

每个数值引用一份具体材料，并保存材料发布日期、观察有效日期、核验日期和材料内定位。任何人工修改都在 Phase 1A 审核项中保留修改前后快照。Phase 1A 的“接受并发布”会立即公开，这是临时产品语义。

演示工作簿中的数字是合成 fixture，不是已核验生产事实。`example.invalid` 链接、`demo_fixture` 类型和 `is_demo=true` 用于防止误用。
