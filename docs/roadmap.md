# Roadmap

Phase 1A 的人工 Excel 闭环和 Phase 1B.1 的单项目资料研究闭环已经完成。后续演进保持以下兼容方向：

## Phase 1B.1 已完成

- 人工创建 research run 并提交官方 URL；
- URL/重定向/SSRF 检查、robots 检查、文件哈希与本地归档；
- PDF/HTML 解析、具体证据定位和研究候选；
- 单位、期间、生产环节及所有权口径校验；
- 管理员一次“确认并发布”或“修改并发布”，不再进入第二个待审核队列；
- 公开项目页来源抽屉和修订链基础能力；
- Kansanshi 首条 First Quantum 官方真实产量记录已经发布，提取方式为 `deterministic`。

## Phase 1B.2 候选范围

1. 接入有独立 API 凭据的在线模型 Extractor，并建立版本化提示词和评估样本；
2. 增加面向官方域名的自动发现，但发现结果仍必须经过抓取安全检查和候选区；
3. 扩展另外四个试点项目并增强 PDF 表格、复杂 HTML 与 OCR 处理；
4. 在严格资格条件下增加批量确认；
5. 评估对象存储、任务队列、定时任务和经过验证的可信来源适配器；
6. 保持当前禁止 AI 无人值守发布的边界，可信来源自动发布另行决策。

任何采集器都必须遵守 robots.txt、网站条款、合理频率以及登录、验证码和付费边界；自动化测试继续只使用许可或脱敏固定样本，不访问实时网络。
