# Roadmap

Phase 1A 仅验证人工 Excel 闭环。后续演进保持以下兼容方向：

1. 将 `sources` 拆分为来源机构和来源文档；增加原始文件归档、哈希、抓取时间、解析状态与证据定位。
2. 将观察记录改为不可变版本，补齐自动转换与人工操作审计日志。
3. 把当前“接受并发布”迁移为：审核批准 → 待发布 → `publication_batches` → 发布、撤回与回滚。
4. 增加管理员、编辑、审核和发布角色的 RBAC。
5. 引入对象存储、任务队列、定时任务和独立 source adapter；采集结果仍只能进入候选区。
6. Phase 1B 优先强化项目/公司维护、导出、导入错误修复体验和 PostgreSQL 集成测试；之后再进入 SHFE、USGS 和矿企试点。

任何采集器都必须遵守 robots.txt、网站条款、合理频率以及登录、验证码和付费边界；测试继续使用许可或脱敏固定样本。
